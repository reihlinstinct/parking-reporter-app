# Languages and the string catalog

`app/src/main/assets/i18n/strings.json` is the only place that names the app's languages
(td423/td424). Code and tests read the languages from it; a test fails if a language code is
written anywhere else in the app's sources (`HardcodedLanguageCodeTest`).

## One block per language

```json
{
  "code": "xx",
  "name": "the language's own name (what the picker shows)",
  "dir": "ltr",
  "default": false,
  "machine_draft": true,
  "plural": "one_is_1",
  "status": "machine-draft, needs native review"
}
```

- `default`: exactly one block, the source language (Hebrew). Missing values fall back to it.
- `fallback`: optional. A language marked `true` is read after the default when a value is
  missing in both the active language and the default.
- `aliases`: optional. Legacy system codes that mean this language (Java may report `iw`
  for Hebrew); used only to match the device locale.
- `machine_draft` and `status`: every language except the default is a machine draft until a
  native speaker reviews it.
- `plural`: the integer plural rule, one of the families in `PluralFamily` (Strings.kt):
  `one_is_1`, `one_is_0_1`, `one_two_other`, `arabic_6`, `slavic_one_few_many`. A plural
  value must carry the categories its family requires.

## Adding a language

1. Add its block to `languages`.
2. Add its value to every key in `strings`.
3. Add `app/src/main/res/values-<code>/strings.xml` with the quick-settings tile label
   (`tile_new_report`). Android picks that label by the device locale, so it stays a resource
   file; `LauncherLabelResourcesTest` checks that the directories equal the catalog's
   non-default languages.

Nothing else changes: the picker lists the catalog's languages by their own names, and the
tests iterate the catalog. `StringsAssetTest` fails until every key has a value in the new
language with the same placeholders.

## Not translated

The app name (the manifest label) stays Hebrew in every language. Everything sent to the city
stays Hebrew whatever the UI language: the report text and the CreateCase payload
(`MunicipalReportTextStaysHebrewTest`), the municipal subject taxonomy, street and address
data, and the Hebrew geocoder in `AddressResolver.kt` (city data, the one allowed code outside
the catalog in main).

## Direction

`dir` sets the layout direction. Values put into a sentence are wrapped in Unicode isolates:
every value in an RTL language, and in an LTR language every value that contains RTL text
(a Hebrew street name in an English sentence).
